# AdMentor AI

An AI-powered marketing assistant that helps improve ad performance with actionable insights and guided suggestions.

---

## Live Demo

https://thinkly-labs-five.vercel.app/

---

## Why I Built This

It was for assignment.

I wanted to build something that feels like a **purpose-built tool**, not just a chat interface.

AdMentor AI is designed to:

* Guide users instead of waiting for input
* Provide actionable ad improvements (not vague advice)

---

## Features

*  **Purpose-Built AI**
  Focused on Meta & Google Ads — not a generic chatbot

*  **Guided Chat Experience**
  Users can start with predefined actions like:

    * Analyze ad copy
    * Improve CTR
    * Reduce ad spend

*  **Dynamic AI Suggestions**
  Each response includes contextual follow-up actions generated by AI

*  **Persistent Chat (localStorage)**
  Chat history is preserved across navigation

*  **Smooth UX**

    * Auto-scroll
    * Enter to send
    * Loading states
    * Disabled actions during requests

*  **Copy to Clipboard**
  Easily reuse AI-generated suggestions

---

##  How It Works

1. User sends a message or selects a guided prompt
2. The frontend sends conversation history to `/api/chat`
3. The API injects a system prompt to shape AI behavior
4. AI returns:

   * Main response
   * Context-aware follow-up suggestions
5. UI renders both response and actions dynamically

---

##  Tech Stack

* **Frontend:** Next.js (App Router), TypeScript, Tailwind CSS
* **Backend:** Next.js API Routes
* **AI:** OpenRouter / OpenAI-compatible APIs
* **Deployment:** Vercel

---

##  Key Product Decisions

* Used **Next.js full-stack architecture** to avoid unnecessary backend complexity
* Focused on **guided UX instead of empty chat screens**
* Implemented **AI-generated suggestions** to make interaction faster and smarter
* Chose **localStorage persistence** for simplicity and better user experience
